# Cyber Safety and Digital Fraud Awareness App

## Project Description
This project aims to create awareness about cybercrime and digital fraud. It educates people about online scams, phishing attacks, UPI fraud, OTP scams and safe internet practices.

## Objectives
- Create awareness about cybercrime.
- Educate people about digital fraud.
- Provide online safety tips.
- Help users identify suspicious links.
- Promote safe digital transactions.

## Group Details
- Group Number: 11C
- Project Name: Cyber Safety and Digital Fraud Awareness App

## Purpose
To help people stay safe online by providing cyber safety information and awareness about different types of digital fraud.
